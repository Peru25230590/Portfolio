# Joshua Tudtud — Cybersecurity & SOC Analyst Portfolio

A single-file, zero-build static web application showcasing Joshua Tudtud's cybersecurity certifications, hands-on security labs, soft skills, and the interactive **SOC-Buddy** 4-stage AI SecOps capstone showcase.

## Included Files
- `index.html` — Complete portfolio web application (HTML5, Tailwind CSS via CDN, Lucide Icons, and interactive JavaScript).

## Before Deploying (Quick Customization)
Open `index.html` in any code editor (VS Code, Notepad++, etc.) and replace the placeholder email `joshua.tudtud.sec@example.com` (2 occurrences near the bottom) with your real email address. You can also add links to your LinkedIn or GitHub profile in the Contact section.

## Free Deployment Options (2026)

### Option 1: Netlify Drop (Fastest — 30 Seconds, No Git Required)
1. Unzip this folder so `index.html` is inside a normal folder.
2. Visit [app.netlify.com/drop](https://app.netlify.com/drop) and sign in with a free account.
3. Drag and drop your folder onto the page to receive a live `https://*.netlify.app` URL immediately.

### Option 2: GitHub Pages (Best for Developer Portfolios)
1. Create a new **public** repository on GitHub (e.g., `joshua-tudtud-portfolio`).
2. Upload `index.html` to the root of the repository and commit.
3. Go to **Settings → Pages**, set **Source** to `Deploy from a branch`, select `main` / `/ (root)`, and click **Save**. Your site will go live at `https://<your-username>.github.io/joshua-tudtud-portfolio/`.

### Option 3: Cloudflare Pages or Vercel
1. Push `index.html` to a GitHub repository.
2. Connect the repository in **Cloudflare Pages** (unlimited static bandwidth) or **Vercel** (Hobby plan) with no build command required (leave build command blank and output directory as `.`).
